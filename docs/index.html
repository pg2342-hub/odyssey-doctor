odyssey-doctor

Static checks for apps built on the Odyssey API JavaScript and Python SDKs. It reads source files only: no API key, no network calls, nothing executed.

Every project has a finding

17 public projects using the SDK, scanned at pinned commits on 2026-11-19

9 checks
12 of 17public projects let browser code reach the API key

Most public apps on the SDK ship the key to the browser and never restart a stream at the 150-second limit. None handle the typed usage-limit errors.

4 of 17 add a server route that hands the raw key to the browser, which moves the leak instead of stopping it. Connection cleanup is mostly right: 11 of the 12 projects that connect from browser code release the connection.

Limits


These are pattern checks, not a type checker. They can miss a key passed through several variables, and they treat any session_timeout handling as a restart. Public code also over-represents hackathon projects, so the corpus counts describe public code, not Odyssey's customer base.

Run it yourself
Python 3.10+, no dependencies. Exit code is 1 when anything is found, so it can gate a CI step.
python -m odyssey_doctor \
  path/to/app
python -m odyssey_doctor \
  path/to/app --json
python -m unittest \
  discover -s tests -v
python corpus/run_corpus.py
